# Mini Instagram (Z-Lite)
Z-Lite is social media application inspired by instagram built using REST APIs with Django REST Framework

## Description
The application allows logged in users and a user can post photos which will be shared across the site and other users can also see the photos.  
search other users by thier name and send friend requests to make friendships.
